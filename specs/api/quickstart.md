# Quickstart Guide: Todo App API

## Prerequisites
- Python 3.13+
- PostgreSQL (or Neon Serverless account)
- Node.js and npm (for frontend, if running full stack)

## Setup

1. **Install Dependencies**
```bash
cd backend
uv pip install fastapi uvicorn sqlmodel python-jose[cryptography] psycopg2-binary python-multipart
```

2. **Environment Variables**
Create a `.env` file in the backend directory:
```env
DATABASE_URL=postgresql://username:password@localhost:5432/todoapp
BETTER_AUTH_SECRET=your-secret-key-here
```

3. **Database Setup**
Run database migrations (if using alembic) or ensure your PostgreSQL database is accessible.

## Running the API

```bash
cd backend
uvicorn src.main:app --reload --port 8000
```

The API will be available at `http://localhost:8000`.

## Testing an Endpoint

Once the API is running, you can test with curl (replace USER_ID and JWT_TOKEN with actual values):

```bash
curl -X GET "http://localhost:8000/api/USER_ID/tasks" \
  -H "Authorization: Bearer JWT_TOKEN"
```

## API Structure

The API follows the structure:
- Base: `/api/{user_id}/...`
- Endpoints:
  - `GET /api/{user_id}/tasks` - Get user's tasks
  - `POST /api/{user_id}/tasks` - Create a new task
  - `GET /api/{user_id}/tasks/{task_id}` - Get specific task
  - `PUT /api/{user_id}/tasks/{task_id}` - Update a task
  - `DELETE /api/{user_id}/tasks/{task_id}` - Delete a task
  - `PATCH /api/{user_id}/tasks/{task_id}/complete` - Toggle completion status

## Authentication

All endpoints require a valid JWT token in the Authorization header. The token must be generated by Better Auth, and the user_id in the URL must match the user_id in the JWT token.
