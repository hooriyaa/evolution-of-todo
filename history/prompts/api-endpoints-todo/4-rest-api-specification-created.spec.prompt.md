# REST API Specification Created

## User Input

```
/sp.specify Create a new specification file at @specs/api/endpoints.md. Title: REST API Specification for Todo App (Phase II) Goal: Define RESTful endpoints for the FastAPI backend using SQLModel. Authentication Requirement: - All endpoints must be protected. - The backend must verify the JWT token from the `Authorization: Bearer <token>` header (generated by Better Auth on frontend). - **Critical Security Rule:** The `user_id` in the URL must match the `user_id` inside the JWT token. Users cannot access other users' data[cite: 162]. Endpoints to Implement: 1. **GET /api/{user_id}/tasks** - Purpose: Fetch all tasks for the logged-in user. - Filters: Support query params for `status` (pending/completed) and `sort` (created/title). 2. **POST /api/{user_id}/tasks** - Purpose: Create a new task. - Body: { "title": "string", "description": "string" } 3. **GET /api/{user_id}/tasks/{task_id}** - Purpose: Get details of a single task. 4. **PUT /api/{user_id}/tasks/{task_id}** - Purpose: Update task title or description. 5. **DELETE /api/{user_id}/tasks/{task_id}** - Purpose: Delete a task permanently. 6. **PATCH /api/{user_id}/tasks/{task_id}/complete** - Purpose: Toggle completion status (True/False). Error Handling: - Return 401 if Unauthorized (No token). - Return 403 if Forbidden (Trying to access another user's ID). - Return 404 if Task not found.
```
