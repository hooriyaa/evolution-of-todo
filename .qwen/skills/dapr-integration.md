# Dapr Integration Skill

## Overview
This skill provides expertise in Dapr (Distributed Application Runtime) integration patterns, including sidecar deployment, service invocation, pub/sub messaging, state management, and external system bindings.

## Core Capabilities
- **Dapr Sidecars**: Understanding of Dapr's sidecar pattern for microservices
- **Service Invocation**: Implementing reliable service-to-service communication
- **Pub/Sub Messaging**: Working with publish/subscribe patterns for asynchronous communication
- **State Management**: Managing state consistently across distributed services
- **Bindings**: Connecting to external systems using Dapr's binding component
- **Secrets Management**: Secure handling of sensitive configuration data
- **Actors Pattern**: Implementing actor-based concurrency models

## Best Practices
- Use Dapr components for configuration management
- Implement proper error handling and retries
- Follow security guidelines for service communication
- Monitor Dapr sidecar health and performance
- Apply circuit breaker patterns for resilience
- Use Dapr's built-in tracing capabilities

## Common Scenarios
- Microservice communication with service discovery
- Event-driven architectures with pub/sub
- Stateful applications with consistent storage
- Integration with external systems (databases, queues, APIs)
- Secure secrets management without code changes
- Scaling applications with actor pattern

## Implementation Guidelines
- Configure Dapr components for different environments
- Use Dapr's API for language-agnostic integration
- Implement proper health checks for Dapr sidecars
- Apply traffic management policies
- Follow Dapr's security model for mTLS
- Monitor and log Dapr operations appropriately
